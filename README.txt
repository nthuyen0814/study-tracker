STUDY TRACKER — HƯỚNG DẪN DÙNG TRÊN ĐIỆN THOẠI

1) Bộ web gồm index.html, manifest.webmanifest, sw.js và icon.svg.
2) Để có một đường link mở được ở mọi nơi và cài lên màn hình chính, cần đưa thư mục này lên dịch vụ hosting HTTPS.
   Cách đơn giản: GitHub Pages
   - Tạo repository mới trên GitHub.
   - Upload toàn bộ 4 file trong thư mục này lên nhánh main.
   - Vào Settings → Pages → Deploy from a branch → chọn main / root → Save.
   - Đợi GitHub tạo link dạng https://ten-tai-khoan.github.io/ten-repo/
3) Mở link trên điện thoại:
   - Android/Chrome: menu ⋮ → Install app hoặc Add to Home screen.
   - iPhone/Safari: nút Share → Add to Home Screen.
4) Checklist được lưu cục bộ trên trình duyệt của từng thiết bị. Không tự đồng bộ giữa điện thoại và máy tính.
